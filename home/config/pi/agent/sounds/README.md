# Pi completion sound

`bip-bop-01.mp3` is OpenCode's built-in `done` sound (also its `default` sound), from [OpenCode at revision 7945de2](https://github.com/anomalyco/opencode/blob/7945de208964a49300d7f770d1a71d078db9a4c4/packages/ui/src/assets/audio/bip-bop-01.mp3). Its MIT license is included in `LICENSE.opencode`.

`PI_NOTIFY_SOUND_CMD` in `home/modules/programs/pi.nix` plays it on macOS at volume 0.4, matching `home/config/opencode/tui.json`.
