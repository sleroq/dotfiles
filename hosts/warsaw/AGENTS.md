# Warsaw deployment notes

Build the system on a capable Linux builder, not this VPS. Its small RAM cannot hold nixos-anywhere's disko closure in the kexec installer's tmpfs. For reinstall, use a small kexec image (the 24.11 image fits), partition and mount the disk with the installer tools, then run nixos-anywhere's `--phases install` with prebuilt `--store-paths` so the system closure is copied directly to `/mnt`. Temporary swap on the mounted disk may be needed during transfer. Verify the disk by-id path before partitioning.

Preserve the existing SSH host ed25519 key with `--extra-files` during reinstall: it is also the age identity needed to decrypt this host's credentials. nginx owns port 80 continuously for HTTP-01 challenges for `waw.cum.army` and `beats.sleroq.link`. It serves Feishin over TLS on loopback port 9443; Remnawave Reality owns public port 443 and forwards unauthenticated `beats.sleroq.link` handshakes to nginx. Keep nginx in the `acme` group for the tunnel certificate, and verify both ACME renewal timers and nginx/tunnel reloads. RU's HAProxy sends all port 443 traffic through the tunnel to Warsaw's dedicated Reality inbound on port 443; the separate RU port 2080 remains the fallback through cumserver. Its local health check cannot detect remote TLS or authentication failures; verify both cover and a real client connection.
